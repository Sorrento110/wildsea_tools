# FOR CODING AGENTS

This project revolves around the Wildsea TTRPG. You have local resources at your disposal as a source of truth for Wildsea TTRPG rules and content.

All official Wildsea TTRPG content lives in `/home/powell/ttrpg/wildsea/`

A text conversion of the core rules is at `/home/powell/ttrpg/wildsea/pdf_to_text_conversions/Wildsea_Core_Rules_1.3.txt`. Use this for an easily parseable text corpus for the Wildsea rules.

If you need to review content from other PDFs, use a simple python script to convert them to a text corpus and persist that corpus in the `/home/powell/ttrpg/wildsea/pdf_to_text_conversions/` directory.
